# SLFPP Assistant — Loan management system sample (Payeconnect)

Loan management system sample for **Society For Less Fortunate People Project (SLFPP)**, prepared by Payeconnect for Lawrence.

- **Demo:** https://geejorgbor.github.io/slfpp-assistant-sample-v2/index.html (role shortcuts: `?role=admin`, `?role=manager`, `?role=officer`; optional `&tab=due`)
- **Proposal:** https://geejorgbor.github.io/slfpp-assistant-sample-v2/proposal.html
- **Hub:** https://geejorgbor.github.io/slfpp-assistant-sample-v2/download.html

Modules: staff login with Admin / Branch Manager (custom role) / Field Officer, multi-branch scoping (Main + satellite offices, add branch), loan products (amount range, weeks/months, simple interest incl. 0%, weekly/monthly/custom cycle, fees, penalties, required deposit), incoming registration and full borrower profiles (DOB, ID/TIN, employment, income, next of kin, documents), loans with item value + initial deposit + auto installment, Processing → Approved (auto schedule) → Active → Closed, due views (all / overdue / today / 3 days / week / month), flexible repayments (multi-select, pay ahead, method, receipt/ref, collector, note, locked paid installments), reminders, loan track record, live dashboard, reports with print + CSV. Accounting and billables shown as “coming next”.

Quote and free demo via WhatsApp **+231 888 916 127**. Sample data only — not live SLFPP records. Amounts in LRD.

Open via GitHub Pages (not jsDelivr) so the HTML renders with its design. Hard-refresh (Ctrl/Cmd + Shift + R) after updates.
