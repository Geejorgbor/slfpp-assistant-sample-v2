# SLFPP Assistant — Sample (Payeconnect)

Staff-assistant sample for **Society For Less Fortunate People Project (SLFPP)**, prepared by Payeconnect for Lawrence.

- **Demo:** https://geejorgbor.github.io/slfpp-assistant-sample-v2/index.html (role shortcuts: `?role=admin`, `?role=officer`)
- **Proposal:** https://geejorgbor.github.io/slfpp-assistant-sample-v2/proposal.html
- **Hub:** https://geejorgbor.github.io/slfpp-assistant-sample-v2/download.html

Features: staff login with Admin / Field Officer roles, dashboard, incoming registration, member profiles, loan track record, Admin loan disbursement with repayment schedule, pay-today / overdue / upcoming reminders, printable reports and CSV export.

Quote and free demo via WhatsApp **+231 888 916 127**. Sample data only — not live SLFPP records.

Open via GitHub Pages (not jsDelivr) so the HTML renders with its design.
